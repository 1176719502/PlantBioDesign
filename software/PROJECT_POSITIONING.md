# BioDesign Studio Product Positioning

## 1. Current Position

BioDesign Studio is a local-first documentation workspace for synthetic biology design records, pathway project notes, traceability review, and documentation-only export/import packages.

The product has moved beyond the earlier single-gene MVP narrative. Expression Wizard remains a core design record subflow, but the top-level product story is now the Pathway Documentation Workspace.

## 2. Primary Users

BioDesign Studio is intended for users who need a local, reviewable workspace for:

- Pathway project notes.
- Pathway steps and gene-level design record links.
- Saved Expression Wizard design records.
- Documentation snapshots.
- Documentation reports.
- Traceability review.
- Documentation-only package exchange.
- Review notes and documentation quality checks.

## 3. Main Product Line

The current product line is:

```text
Pathway Projects
-> Pathway Workspace
-> Expression Wizard as a design record subflow
-> Design Library / saved design records
-> Documentation snapshots
-> Reports
-> Traceability
-> Documentation-only export/import package
-> Review notes and documentation quality checks
```

## 4. Historical Context

Earlier product documents described BioDesign Studio as a single-gene Expression Wizard MVP. That was a useful baseline and remains preserved as historical context.

Current copy should avoid presenting single-gene expression design as the whole product identity. Where older release notes or acceptance documents are referenced, label them as historical or earlier MVP records.

## 5. Product Boundary

BioDesign Studio does not provide:

- Wet-lab automation.
- Experimental validation.
- Biological readiness approval.
- Prediction of biological outcomes.
- Pathway optimization.
- Biological-action recommendation.
- Protocol generation.
- Autonomous DBTL execution.

Every top-level description should make clear that exports, imports, reports, snapshots, traceability summaries, and review notes are documentation-only records.

## 6. Differentiation

BioDesign Studio is lighter than full commercial design platforms and narrower than lab automation systems. Its value is the local documentation loop:

- Capture pathway project records.
- Link design records to pathway context.
- Preserve documentation snapshots.
- Review traceability and missing references.
- Exchange documentation-only packages.
- Keep safety and scope boundaries visible.

## 7. Copy Rule

Use wording that emphasizes "local-first", "documentation-only", "design record", "pathway project notes", "traceability review", "documentation snapshot", "export package", "import preview", "duplicate guard", and "review notes".

Avoid wording that implies experiment execution, biological approval, prediction, optimization, or autonomous decision-making.
