# PlantBioDesign V1.0 软件简介

中文 R4 正式公开文档 · 2026-10-10

## 研究背景与开发目的

植物表达构建设计涉及宿主、编码序列、调控元件、骨架及结果文件。材料分散时，来源、版本和设计记录难以对照。PlantBioDesign 面向植物学、生物学与合成生物学研究者，将这些材料纳入同一计算设计与人工复核流程。

## 主要功能与六步方法

软件以项目定义→目标基因→植物表达盒→载体骨架→完整构建→结果与导出组织单基因流程，提供输入检查、表达盒组装、固定规则骨架插入、质粒图、项目保存与重开，以及FASTA/GenBank序列和JSON备份导出入口。


## 元件来源与可追溯性

设计需要记录accession及版本、来源物种、提取坐标、方向、原始文件和核酸SHA-256。元件库资格与用户序列路线应分开理解；输入被接受不等于来源审核完成。当前来源汇总有缺口，需单独保留原始来源记录。

## 实际计算案例

水稻宿主的人ALB单基因案例使用 `NM_000477.7` CDS（1830 bp）、来自 `AF485783.1` 的CaMV 35S（835 bp）与NOS（253 bp），组成2918 bp表达盒；向 `AF234296.1` 的8958 bp环状骨架固定正向27|28边界插入，得到11876 bp质粒。既有记录支持输入身份及序列级重建核验；不证明水稻表达、产量或生物学功能。详细来源、哈希与命令见配套案例说明。

本 ALB 单基因操作例是独立操作示例，不是论文 MT-01 或 MT-02 的结果。论文案例分别为 4079 bp 双转录单元和 6609 bp 三转录单元来源区域，均未证明独立完整质粒重建。
